# Security Review

Review:

- Input validation
- Authentication and authorisation
- Personal data exposure
- File upload handling
- SQL injection risks
- Cross-site scripting
- Cross-origin configuration
- Secret management
- Error information leakage
- AI prompt injection
- Untrusted AI outputs
- Audit integrity

Never expose API keys to React.

Never commit secrets.

Use fictional data during development.

Report findings with severity, evidence and remediation.

Do not claim a system is secure solely because tests pass.
