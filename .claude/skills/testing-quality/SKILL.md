# Testing and Quality

- Write tests for new business logic.
- Test valid and invalid API requests.
- Test anonymous and identified reporting.
- Test attachment validation.
- Test incident lifecycle transitions.
- Test permissions when authentication is implemented.
- Test AI outputs with controlled fictional examples.
- Test human approval requirements.
- Include regression tests for fixed defects.
- Report actual test results.
- Never claim tests passed without execution.
