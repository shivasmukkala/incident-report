# Frontend Development

- Use React functional components.
- Keep components reusable and focused.
- Separate API calls from UI components.
- Use accessible semantic HTML.
- Associate every form input with a label.
- Provide loading, success and error states.
- Support mobile, Tablet and desktop layouts.
- Avoid unnecessary dependencies.
- Never expose API keys or secrets in frontend code.
- Test important interactions and validation.
- Do not use mock data as if it came from the real backend.
