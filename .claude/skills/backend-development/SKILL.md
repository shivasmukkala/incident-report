# Backend Development

- Use FastAPI and Pydantic.
- Keep API, business logic and database responsibilities separate.
- Validate every incoming request.
- Use appropriate HTTP status codes.
- Handle exceptions safely.
- Use database transactions where necessary.
- Generate unique case references.
- Keep business rules testable.
- Validate file uploads.
- Never return confidential information unnecessarily.
- Write tests for API behaviour and validation.
