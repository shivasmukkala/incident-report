# Accessibility Plan

## Design Requirements

- Semantic HTML.
- Properly associated form labels.
- Keyboard-accessible controls.
- Visible focus indicators.
- Readable text and sufficient contrast.
- Clear validation messages.
- No colour-only status indicators.
- Responsive mobile layouts.
- Accessible file upload controls.

## Voice Accessibility

- Voice input must be optional.
- All reporting functions must remain available through text.
- Microphone permission must be clearly explained.
- Transcribed information must be editable.
- Errors must be communicated through accessible text messages.

## Testing

- Keyboard-only navigation.
- Screen-reader label review.
- Colour contrast review.
- Form validation review.
- Mobile viewport testing.

Target: WCAG 2.2 AA.

Record actual findings and limitations after testing.
Do not claim compliance without evidence.
